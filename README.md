# PUBG SENS LAB

面向 Steam 版 PUBG 键鼠玩家的单文件灵敏度调试助手。它通过浏览器内的追踪、定位和 360° 转身测试，结合鼠标 DPI、握法、鼠垫空间、压枪习惯与常用枪械配件，生成一组可直接填入 PUBG 设置页的灵敏度建议。

## 功能

- 追踪测试（10 秒）：准星跟随移动目标，以有效悬停时间评估追踪稳定性。
- 定位测试（10 秒）：鼠标碰到随机目标即判定命中，统计命中数和反应速度。
- 360° 转身测试：结合 DPI 和桌面实测距离估算 `cm/360°`。
- PUBG 参数生成：输出常规灵敏度、垂直灵敏度增强、瞄准灵敏度、开镜模式灵敏度，以及红点、2 倍、3 倍、4 倍、6 倍、8 倍和 15 倍镜灵敏度。
- 配件负载建模：可组合枪械、握把、枪口和枪托配置，以常用度加权生成建议。
- A/B 微调：根据“横向过冲、跟不上目标、纵向压不住、下拉过量”等实际感受给出下一轮修正值。
- 本地保存与导出：配置和测试记录保存在当前浏览器，可导出 JSON 备份。

## 使用方法

1. 下载并打开 [`PUBG专属灵敏度调试助手.html`](./PUBG专属灵敏度调试助手.html)。
2. 填写鼠标 DPI、当前游戏灵敏度、握法与鼠垫空间。
3. 配置常用武器及配件，并设置使用权重。
4. 依次完成追踪、定位和 360° 测试。
5. 生成推荐值，将结果手动填写到 PUBG 的“控制—鼠标”设置中。
6. 在训练场至少验证两轮，再使用 A/B 微调功能逐步收敛。

整个工具只有一个 HTML 文件，不需要安装依赖，也不会连接游戏进程或修改 PUBG 配置文件。

## 使用建议

- 测试时保持与游戏相同的鼠标 DPI、Windows 指针速度和可用鼠垫空间。
- 关闭浏览器缩放，建议在桌面浏览器全屏状态下测试。
- 配件模型用于估算常用负载的综合需求；PUBG 本身并没有“按握把单独设置灵敏度”的选项。
- 浏览器测试无法完全复刻 PUBG 的视野、后坐力和输入链路，最终值应以游戏训练场中的实测为准。
- 每次只微调一个维度，小步修改后至少进行两轮对比，不要一次大幅改动所有倍镜。

## 数据与隐私

所有输入、成绩和方案默认仅保存在浏览器本地。导出文件中不包含账号密码或游戏登录信息。
